# PL460Arduino development repository

The Arduino library is in [`PL460Arduino`](PL460Arduino/README.md).

That directory contains the complete user documentation, examples, firmware
provenance, safety information and mixed-license notice.

## Public-release warning

This development repository also tracks the original `G3_v2.1.0` SDK bundle.
The SDK is not required to build the Arduino library and contains many
third-party components. Do not make this entire repository public until every
SDK component and its redistribution terms have been separately audited.

For a clean public release, publish the `PL460Arduino` directory as its own
repository root and retain all license and notice files contained there.
